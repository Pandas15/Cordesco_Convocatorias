# CORDESCO · Corporación Desarrollo Social y Comunitario

Sitio oficial de convocatorias de **CORDESCO — Corporación Desarrollo Social y Comunitario**
(NIT 830.508.876-8 · Reg. Merc. S0502491 de 2004).

Publicado con GitHub Pages.

## Estructura

```
index.html            Portada: aviso de convocatoria + registro de avisos
postulacion1.html     Convocatoria 1 — Aguachica (Cesar), Educación Inicial en el Hogar (740 cupos, 6 cargos)
logo_cordesco.png     Logo oficial
documentos/           Formatos ICBF que firma el aspirante (.doc para diligenciar + .pdf para leer)
.nojekyll             Evita el procesamiento de Jekyll en GitHub Pages
```

## Formatos descargables (`documentos/`)

- `01_autorizacion_tratamiento_datos_personales` — formato ICBF **F5.P21.GTH** v3
- `14_autorizacion_consulta_inhabilidades` — formato ICBF **F7.P17.GTH** v1

Son los formatos institucionales del ICBF (no llevan marca de ninguna corporación), así que sirven tal cual
para cualquier asociación operadora.

## Cómo se monta una convocatoria nueva

Se crea `postulacionN.html` con el mismo diseño, se agrega la tarjeta en el listado de
`index.html` y se toma de la guía operativa del servicio ICBF la lista de cargos y perfiles
(no se reciclan de otra modalidad).
